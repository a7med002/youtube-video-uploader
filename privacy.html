Privacy Policy

Effective date: November 25, 2026

Overview

YouTube Video Uploader is a personal desktop application used to upload and schedule videos on an authorized YouTube channel.

Data Access and Use

The application uses Google OAuth and the YouTube Data API to authenticate the channel owner, upload videos, set thumbnails, manage video metadata, and schedule publication.

Data Storage

Authentication tokens and upload records are stored locally on the owner's computer. They are used to maintain authentication and prevent duplicate uploads.

Data Sharing

The application does not sell Google user data or use it for advertising. Video files and associated metadata are transmitted to YouTube to perform authorized publishing operations.

Data Retention and Deletion

Locally stored authentication tokens and upload records can be deleted by the application owner. Google account access can also be revoked through Google Account security settings.

Google API Services

The application's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking Access

Access can be revoked at any time through Google Account Connections.
